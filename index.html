Susun section (intro, verse, chorus), beri pola berbeda untuk tiap bar, atur keras-pelannya tiap not, lalu putar satu section atau seluruh lagu. Kode Tone.js untuk arrangement penuh dibuat otomatis di bawah.

Ketuk berulang: ghost, normal, aksen, lalu kosong. Desktop: Shift+klik aksen, Alt+klik ghost, klik kanan hapus.

Urutan lagu

Ketuk nama untuk mengedit section itu. Satu section bisa dipakai berkali-kali.

Ekspor

Simpan section yang sedang dibuka, atau seluruh lagu beserta urutan dan tempo. JSON bisa diimpor kembali ke aplikasi. MIDI untuk dibuka di DAW (channel drum, swing ikut dihitung). WAV adalah hasil render audio (memakai suara kit baru). MIDI dan WAV dikemas dalam file zip karena unduhan di halaman ini hanya menerima ekstensi tertentu.

Import pola

Tempel JSON atau pilih file .json / .mid. File dibaca di browser ini saja dan tidak diunggah ke mana pun. Pola dari AI sebaiknya didengarkan dan dikoreksi sebelum dipakai. Kalau "pilih file" tidak bereaksi (sebagian aplikasi membatasi pemilih file), buka file JSON-nya, salin isinya, tempel ke kotak di bawah, lalu ketuk "baca teks". Di desktop, file juga bisa diseret ke kotak teks.

Diagnosa audio (mencari penyebab suara pecah)

Monitor mengukur tiga hal saat lagu diputar: puncak volume (clipping), not yang terlambat dijadwalkan, dan beban pemrosesan. Aktifkan, putar seperti biasa sampai terdengar pecah, lalu salin laporannya dan kirim ke saya. "Uji clipping offline" merender pola padat di kit baru dan lama tanpa perlu didengar.
